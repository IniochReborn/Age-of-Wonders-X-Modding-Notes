User decisions 10/20:
- Hosting: 420 is the last HeavenGames upload; afterwards installers on the user's GitHub Releases; aowx.org (Cloudflare) hosts the signed notice (e.g. /update/latest.json + .sig; test channel /update/test/).
- Verify: notice signed with the user's offline private key (ECDSA/RSA, public key in updater) AND installer SHA-256 must match the notice from aowx.org; newer-than version check only.
- Updater: small .NET Framework program AoWxUpdater.exe (my recommendation, user agreed).
- Modes (AoWSetup → Developer): Automatic (default) / Ask before installing / Off.
  - Automatic: download only WHILE AoWx is running (started at game launch); install silently when the game is CLOSED; title shows 'update ready - installs when you quit'-style note.
  - Ask: popup at game START ('Update to 1.37.4xx? Update now / Not now'); yes → game closes, download + install.
  - Off: no checks, no title line.
- Background checks: scheduled task at log-on +2 min and daily 4:20 PM — CHECK ONLY (record status in registry), never download when AoWx isn't running.
- Title screen: green 'AoWx is up to date!' / red 'Update available!' above the version; red glows/grows on hover; click → confirm (tutorial-style Yes/No dialog) → close game → updater installs. Typing 'update' on the title screen triggers a check (like inioch/ziggurat eggs).
- Test plan: set game version to 415 temporarily (NOT in the manual), install on laptop, publish 420 to the test channel, test the full flow + tamper cases, then go public at 420.
