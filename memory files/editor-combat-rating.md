**GOAL:** Show a display-only combat rating in the editor's unit window (TUnitResourceEditForm), in the empty space below Transport Capacity.

**FORMULA (agreed w/ user):** `Score = (Attack + Damage + AbilityPoints/10 + 10) × (Defense + Resistance + 10) × (Hits + 10)`. Mirrors the game's real strength formula: GetStrength = (offense+10) × defensiveStrength; **defensiveStrength = (Defense + Resistance + 10) × (Hits + 10)** (from AoWEPACK TAbstractUnit.UpdateDefensiveStrength @0x5577F714, virtuals +0xc4=def,+0xcc=res,+0xe0=HP). AbilityPoints = sum of owned abilities' TAbility.GetSkillPoints, ÷10 (user: raw was weighted too high). GetCombatValue @0x5577F9A8 is the AI's real value but needs a live TAbstractUnit + runtime global [0x558fa044] (set by TAoWEngine.CreateHSSet) — NOT usable on the editor's TUnitResource, so we compute from the form's own controls instead.
