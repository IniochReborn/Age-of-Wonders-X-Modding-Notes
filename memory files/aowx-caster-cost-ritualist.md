Live 410 AoWEPACK.dll (checked 2026-09-13) carries BXL's caster_cost feature (ids 0xAC Evoker / 0xAD Conjurer / 0xAE Enchanter / 0xAF Ritualist) but as a LAPTOP PORT, not BXL's reference build: caves at 0x55814F00 (cost classifier on THero.CastingMana entry 0x557894EC), 0x55814F80 (TGlobalEnchantmentSpell.Activate wallet fix @0x557EFA7C), 0x55814FA0 (TSummonSpell.Activate wallet fix @0x557E44F8), 0x55814FC0 (registration via splice 0x557BCF04); TSummonSpellTE.Process 0x557E4353 patched in place. No epilogue floor hook (0x55789510 vanilla); discount is cost − (cost+1)/3, never 0 for cost ≥ 1. The install script is NOT on the desktop (only BXL's reference copies under `reference files\...\build_caster_cost.py`, which halve and target AoWEPACK.dpl).

⚠ Classification differs from BXL: summon (Δ0x6B27C) / unit (Δ0x1FF4) / combat (Δ0x120 + 0x7E034) are explicit, and EVERYTHING ELSE falls through to Ritualist 0xAF — i.e. all 50 non-summon/unit/combat spell classes (13 TGlobalEnchantmentSpell, 14 TGlobalTargetSpell, 10 TCityTargetSpell, 7 TStormSpell, plus ConcealArea/BirdsView/WarpParty/Disjunction/ResurrectHero/AnimateHero/CallHero/Crusade), not just the 13 global enchantments.

Cost/wallet chain: THero.CastSpell 0x55789854 → instant branch iff CastingMana ≤ [hero+0x80] (casting points) → spell CanActivate [vmt+0x68] / Activate [vmt+0x6C] → TSpellTE.Create 0x55779884 (edx=spell id→[TE+0x10], [ebp+0xC]=caster id→[TE+0x14], cl=player→[TE+0x18], [ebp+8]=COST→[TE+0x1C]). TSpellTE.Validate 0x557798B8 (slot +0x50) → 0x55789640(hero, spellid, [TE+0x1C]) fails when cost > [hero+0x80]; TSpellTE.Process 0x55779948 (+0x4C) calls Validate then Execute (+0x54; base 0x5577991C → spell [vmt+0x50] with the TE). TGlobalEnchantmentSpellTE VMT 0x557ED91C overrides +0x50 (0x557EF85C, chains to base) and +0x54. GetSource 0x557798A0 resolves caster unit from [TE+0x14].

Of 27 TSpellTE.Create callers only the two Activate caves push the discounted cost; the other 25 push RAW [spell+0x14] (all 7-byte windows `8b 4x 14 50 8a 4x 24` / `8b 47 14 50 8b 57 10`, all .reloc-free): TGlobalTargetSpell target-picked fns 0x5579EC96 0x5579F00E 0x5579F38A 0x5579F6B2 0x557A20BE 0x557A221E 0x557A36D2 0x557C4B9A 0x557C896E 0x557C9AEE (eax=spell esi, edx=caster edi); Activate-style 0x557A0281 0x557A1025 0x557A18E9 0x557CDBB9 (edi=spell, esi=caster) and 0x557EA6A2 0x557EAC4E 0x557EC476 0x557ECA16 0x557ECB79 0x557ED6CA (esi=spell, ebx=caster); TCityTargetSpell 0x557B097E (eax=spell, ecx=caster); Disjunction 0x557EBC8B pushes cost of spell 0x33 with TE id = target enchantment (special case). Water Mastery ExecuteTE 0x557F0A88 reads raw too.

**Why:** with a discount D < raw R, the band D ≤ points < R enters the instant branch, the TE is created with R, Validate rejects it → spell "starts" (targeting/animation) then silently does nothing and charges nothing. Reported by the user 2026-09-13 for Ritualist.
