- UI text pipeline in AoWx.exe: LoadResString (VCL30 thunk 0x401180) → AoWE.TranslateRStr (AoWEPACK thunk 0x4021E4; localization lookup, unknown text passes through) → control SetGText (aowInt thunks: TAOWLabel 0x403254, TAOWEdit 0x40326C, TAOWListBox.SetIndex 0x40365C / SetListOff 0x403664). Exe resourcestrings: ResStringRec {module-ptr 0x45B004, id} pairs; "Party Action" family ids 65488–65498 in .rsrc block 4094. AoWEPACK exports its own RStr recs (GuardRStr="Guard", GuardAreaRStr="Guard Area") but the in-game "-ing" forms come from the exe.
- Party Action label switch @0x4051D8 in AoWx.exe: value = TArmy.GetBehavior (thunk 0x40280C) & 0x7F, 11-slot jump table @0x4051EB (index = gb enum: 0 gbNone→Wandering, 1 Patrol, 2 Guard, 3 GuardArea, 4 Scout, 5 Refuge, 6 Raid, 7 Aggressive→Hunting, 8 Defensive→Protecting, 9 Fortify, 10 Suicidal→Berserk, >10→Wandering). Each case: string → TranslateRStr → SetGText([edi+0x174]) → jmp 0x405527. Slot 3 was patched (build_guardarea_label.py) to a cave showing "Guarding Area".
- AoWx.exe cave space: .idata tail slack (file = VA-0x402400), executable since the raze-UI patch. Used: 0x46E380–0x46E39C (raze UI), 0x46E3A0–0x46E3D6 (guard-area label). Free: ~0x46E3E0–0x46E400 only (tiny); for bigger caves consider the .xbfs section (va 0x60D000, 0x2000 raw). CODE tail slack (20B, VA 0x459FEC–0x45A000, file = VA-0x400C00): now FULL (savedate stub). DATA tail slack (VA 0x45A634–0x45A800, file = VA-0x400C00, R/W not executable — data only): 0x45A634–0x45A680 used by savedate import name + format literal, free 0x45A680–0x45A800. Delphi string literals for patches: dwords {-1 refcount, length} then chars+NUL; pass pointer-to-chars.
- Save-timestamp fix (build_savedate_format.py, applied 2026-08-23): Load/Save DateLB dates were DateTimeToStr(FileDateToDateTime(...)) using raw Windows LOCALE_SSHORTDATE (modern "M/d/yyyy" + AM/PM ≈ 20 chars, overflowed 130px DateLB → garbled tail). Fixed by repointing the exe's ONLY DateTimeToStr import: new hint/name entry "SysUtils.DateTimeToString@73F58862" in DATA slack, ILT/IAT slot 0x45D404 → it, stub @0x459FEC does mov edx,fmt("yyyy-mm-dd hh:nn:ss" @0x45A664); call site 0x41F89E → stub. DateTimeToString = DateTimeToStr layout (eax=^Result, TDateTime on stack, ret 8) + edx=Format. Format uses DASHES for the time too ("yyyy-mm-dd hh-nn-ss") because Age8's ':' glyph is two isolated 1px dots ≈ invisible — and note Delphi format chars ':' / '/' mean locale Time/DateSeparator, only '-' is a true literal. build_age8_colon.py (bolder ':' glyph in Int\Fonts\Age8.ILB) was applied then REVERTED 2026-08-23 at user's request (global font change, user said it didn't show anyway — possibly the game caches/preloads fonts or uses a different source at runtime; unverified). Age8.ILB is back to pristine. ILB font facts: glyph image id = ASCII code, advance = 'wide' field, all glyphs ink = palette idx 1 (remapped to TextColor at draw); RLE08 = per-bb-row u32 len (incl itself) + payload (byte==transparent-idx ⇒ next byte = transparent run count, else literal pixel); format docs in "old modding tools\IlbMaker_*\ILB desc.pdf" + AoW1Graphics.cs; scratchpad-style parser in patch script's parse(). ⚠ Python: `o += u32()` where u32 mutates o via nonlocal silently loses the mutation (left operand loads first) — read into a temp, then add. IMPORT-REPOINT TECHNIQUE: Borland exes have OriginalFirstThunk=0 (FirstThunk doubles as ILT), so pointing the slot's name-RVA at a new hint/name entry anywhere readable (DATA slack works) swaps which vcl30 export a thunk resolves to — no GetProcAddress needed. vcl30 mangled export names come from the export table (scratchpad vcl_exports.py pattern).

**Why:** any future text change or new UI string in AoWx.exe reuses this exact machinery.

**How to apply:** for new display strings prefer a cave literal fed through TranslateRStr so localization stays consistent. Related: [[aowx-project-overview]], [[aowint-toolkit-internals]].
