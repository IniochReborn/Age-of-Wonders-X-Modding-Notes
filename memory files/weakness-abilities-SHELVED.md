**GOAL (user):** New "Weakness" abilities = inverse of vanilla Protections. Unit with e.g. Fire Weakness takes **+50% fire damage** and **+status-effect chance** (same magnitude Protection reduces). If unit has BOTH Protection & Weakness for a type → cancel (normal). If Immunity & Weakness → immunity wins, weakness cancelled. Fire Halo (=fire immunity), Liquid Form (=physical protection), Blessed (=death protection) must cancel their weaknesses — AUTO-HANDLED because they're in the game's GetImmunityTypes/GetProtectionTypes masks.

## DESIGN — SOLVED (both hooks + cancellation)
- **DAMAGE: TAbstractUnit.ExecuteDamageRole @0x55781AC4** (funnel; param_1=unit, param_4=dmg types). Vanilla: `imm=GetImmunityTypes[+0xec](); if(types&~imm)!=0 { dmg=roll; prot=GetProtectionTypes[+0xf0](); if((types&~prot&~imm)==0) dmg=(dmg+1)>>1; }`. WEAKNESS INJECTION: compute `weak` mask (from our new abilities), `effP=prot&~weak`, `effW=weak&~prot&~imm`; halve when `(types&~effP&~imm)==0`; if `(types&effW)!=0` → dmg = dmg*3/2 (×1.5). (weak cancels prot; prot/imm cancel weak; imm still fully negates.)
- **STATUS EFFECTS: TAbstractUnit.ExecuteDamageEffectsRole @0x55781BA4**. Per damage-type block: base effect-strength (Fire4/Cold3/Lightning6/Poison3/Death4/Holy3), rolls `HitRole[0x55725d98](strength - RES)`; RES=[+0xcc](). Protection does **RES+2** (`else iVar5=iVar4+2`). WEAKNESS = **RES−2** (mirror). Per-type: effP→RES+2, effW→RES−2, else RES. (6 blocks: bits 1,2,4,0x10,0x20,0x40.) So the "amount" = **±2 RES** (confirmed).
- Cancellation reads the game's own VMT GetImmunityTypes(+0xec)/GetProtectionTypes(+0xf0) → any protection/immunity source (Blessed, Fire Halo, Liquid Form, items, enchantments) cancels automatically.
- Weakness mask computed via HasAbility [unit+0x88 or strategic +0x148 GetAbilityEnabled](id) for each of our 8 weakness ids (like the aggregators do).
