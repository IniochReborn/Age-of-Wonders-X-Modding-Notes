Ability bitset: [unit+8] dword array, count [unit+0xC] (TAbstractUnit.GetAbilitySet 0x5577F618); ability objects: AoWHSSet [0x558FA044]+0x80 -> TAbilityControl -> [+8] TList indexed by id; TRangedAttackAbility data: +0x28 range, +0x29 damage, +0x2A attack, +0x2B damage-types word, +0x2D repeats (Doom Gaze 0x37 IS a plain TRangedAttackAbility: range 3, dmg 2, atk 6, repeats 2; AbilTypes cat 11 -> case 2 -> ranged handler 0x417420 via case-map 0x416DC2 / table 0x416DE8; in the in-range id switch 0x4175AD it takes the normal projectile branch 0x41761F).

**What the capture showed (2 AI cycles):** cycle 1: Shaman proposed 13 attacks (incl. type-3 shoot 88468) -> executed; hero/leader gated (hero gate: phase-1 enemy loop skipped when [cai+0x2C]!=0 @0x418E89). Cycle 2: Shaman spent; hero produced only type-4 "approach-melee" temps (deleted in phase 4 by design — a hero with UnitSafe<0 never gets real type-0 melee approaches, vanilla) plus ONE type-1 SELF-heal (value 30100, target = self, dest = own hex 46,28) from the healing patch's cave F; the leader was gated by that heal's [cai+0x2C]++; phase 5 took the heal -> turn state 2 immediately = the move was DROPPED: **TCAI phase-5 touch executor 0x41ABD0 walks the path [ctx+0x68] to the destination and touches at its end; `cmp [path+8],1; jle 0x41AE17` @0x41ACE4 (and again after MakeTerrainPath @0x41AD21) drops any 1-node path without executing and without setting [ebp-0x31]`**. So the self-heal is dead weight every turn: it silences the leader and, once no other move exists, ends the AI turn. (Vanilla's own self entries in the friendly loop have the same fate but score pct 1, so they never top the list.)

**Engine support for touch-without-moving:** `TTacticalCombatUnitHS.AbTouchMoveTC` 0x423744(eax=hs, edx=path): count>1 -> CreateTCAbTouchMoveTE token; count==1 -> GetAbility([hs+0x34]) -> GetCombatInfo(unit) byte0&1 (friendly) -> `AbRangedTC` 0x423860(eax=hs, dx=x, cx=y) on path[0] — but returns 0 in that branch. THealingAbility.CanTouch 0x5576C14C and TTouchAbility.CanTouch 0x557682AC have NO self check. Phase-5 type-3 executor calls AbRangedTC(hs, dx, cx) directly and stores al -> [ebp-0x31]. Phase-5 jump table 0x41A4E8: type0/5 -> 0x41A500, 1 -> 0x41ABD0, 2 -> 0x41A9EA, 3 -> 0x41AE24, 4 -> 0x41AEF1 (drop). Phase 5 loop 0x41AF10: executed ok -> exit loop (next cycle); failed -> delete move, try next; none left & nothing executed -> [cai+0x36]=2 (turn over).
