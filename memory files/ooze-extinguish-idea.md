**How Ooze really works (all in TCPCK CombatTE.TCAbRangedTE):**
- Execute phase 0 (0x40B4E6 switch on [te+0x24] = spell "kind" from table [0x4693F8][spell id]): kind 0xA → spell 0x74 gets 0x15 strikes, **spell 0x7C (Ooze) 0x13 = 19 strikes** ([te+0x28]); 19 = radius-2 hex blob = the "5x5" the user sees. Other kinds: 0x14/0xA strikes etc.
- NextStrike 0x40D290: per strike AddEffect(map, type 0) → **TfxHS** (class [0x411FE8]; [fx+0x14] ability type (0x34 = spell), [fx+0x18] spell id, [fx+0x1C] target HS, [fx+0x24]/[+0x28] x/y, [fx+0x34] TfxType enum 0..0x31, [fx+0xC] landed flag), fields set per kind. TfxType names at RTTI 0x411630 (fxArrow, fxComet, fxBreath, fxScreenNS 0xA, fxDamFire 0x11, fxWallSmoke 0x1A, …); TfxHS.NewFrame 0x429E78 jump table 0x429EF7.
- Execute phase 1 (state [te+0x38]==1 → 0x40B776): loop over the map's fx TList `[[0x469420]+0x11C]` (count +8, TList.Get thunk 0x40153C); for a landed fx: hex via aowFX.TXYZList.GetXYZ (thunks 0x402DFC/0x402DF4) + HSEngine.HPtoHX 0x4022C4 → x=[ebp-0x28], y=[ebp-0x2C]; then dispatch on [fx+0x14] (0x2C/0x18/0x1E/0x1F/0x34…) → for 0x34 on [fx+0x34]: 5 → msg 0x31013; 7 → spell 0x71: msg 0x3100B + CreateFire; **0xA → spell 0x74: msg 0x31006; spell 0x7C: 0x40C922** = GetMapLevel(container [[0x469420]+0x10],0) (thunk 0x401E64) → GetField(level, x, y) (0x401E54); skip if [field+0x14] terrain ∈ {0,7,9,0xF} or [field+0x15] ∈ {2,8,0xB}; else `TEObject.Create([0x41275C] TCOozeHS)` + THSMap.PlaceHX(map, hs, x, y) 0x402264 → the mud decal (TCOozeHS ClassID 0x220109, overlay 0xB, Show 0x424190 picks lib [[0x46E8D0]+0x94] seq 0x19/0x1A/0x1B by terrain). - TDamageCA side (AoWEPACK) is a no-op for Ooze (0 strikes, types word 0); fast combat: nothing.

- `field.VMT+0x80` = **HSEngine.TMapField.FindOwnedChild(eax=field, edx=ClassID)** → HS or nil (scans [field+8][i], count [field+0xD], `[hs].VMT+0x24` ClassID, owner [hs+4]==field). VMT+0x7C = FindChild (no owner test).
- Fire: while FindOwnedChild(0x22054A TCombatFire) → System.TObject.Free (thunk 0x401050; THexagonSprite.Destroy 0x55605CB0 calls VMT+0xB8 remove-from-map first — same idiom TCombatFire.NewTurn uses).
