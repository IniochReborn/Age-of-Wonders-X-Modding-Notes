**Legendary is NOT a rank**: TUnit.GetRank 0x5578294C still returns 0/1/2 (flat XP 10/20). Legendary = rank 2 AND "HP capped" via cave 0x5580EF60 (ebx=unit; CF clear = capped; preserves eax/ecx/edx): `(XP div 10)*2 + baseHP >= max((7-tier)*baseHP/2, baseHP+6)` with baseHP=[res+0x2C], tier=[res+0x2F], XP=[unit+0x3C] → a pure function of XP, so the transition only happens where XP changes. Medal painter/flag caves 0x5580F00F/0x5580F060 OR 0x80 into the rank for the icon.
