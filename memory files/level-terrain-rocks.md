**Feature (user 2026-09-21):** Level Terrain flattens mountains/hills to bare terrain; now it spawns decorative rocks of the hex's terrain type (overlay 0xFF = no movement cost). Script `patch scripts\patch_level_terrain_rocks_v1.py` (AoWEPACK.dll, backup `backup\AoWEPACK.dll.bak_lvlrocks`). **APPLIED 9/21, awaiting in-game test** (surface mountain/hill → rocks; forest/plain hexes in the radius stay bare; underground earth walls → dirt + UG rocks). Next free AoWEPACK cave **0x55816F00**.

**Why:** bare hexes after leveling looked lame; rocks read as rubble and keep the spell's purpose (no penalty).
**How to apply:** hook 0x5579F109 in the TLevelTerrainTE worker 0x5579F068 (5 B `0f be 47 22 50`) → cave_lvl (records pre-clear terrain<<8|overlay, replays ClearTerrain + earth→dirt, then rocks if overlay∈{0 Mountain,2 Hill} or pre-terrain 7) → cave_rocks = PlaceTerrain clone with decoration filter → resume 0x5579F153.
