**Shared path builder AoWTC.MakeRangedPath @0x427630 (AoWTCPCK.dll)**, used by the UI (TCombatUnitSelectionControl.CalculateRangedPath 0x41DC58 → TRangedPathHS.Show prints rec+8 via IntToStr @0x428823), the AI (TCAI.EvalPath 0x414DA8) and the executor (TCAbRangedTE.NextStrike, MakeAbilPath call @0x40ED9B) — all three see the SAME per-hex numbers. Args: al=side, dx=sample density (0x32 ≈ 2 samples/hex, 0x19 ≈ 4, 0xA in NextStrike's other call), cx=arc height (0 flat; 0x14/0x23/0x32/0x64), stack: &TList (block records: +4 point index, +8 block % 0..100), &TXYZList (pixel points, +0xC arc height), byte "units block" (1 everywhere except EvalPath's breath call), x/y offsets, target hex, shooter hex. AoWTC.MakeAbilPath 0x4271EC picks dx/cx per ability id: 0x16/0x18/0x19 → arc 0x64 (lob); 0x2C/0x2D/0x39/0x3A/0x7B → arc 0x14; 0x37 Doom Gaze → flat, dense; 0x1E/0x1F/0x56–0x5A breaths → single point (no path); default → arc 0x32; id 0x34 spell → per SpellTypes table.

Per sample point (shooter's and target's own hexes never block), category → block value: field byte +0x14 ∈ {7, 0xF} → 100 (terrain); dist-from-shooter == 1: ENEMY unit → unit formula, intact wall (+0x20 hp > 0) and side 0 → 50 flat; dist > 1: ANY unit (friend or foe) → unit formula; no wall and field +0x15 == 8 (obstacle overlay) → unit formula; intact wall at dist > 2 → 200 − 3·arcHeight (dist == 2 walls are ignored when the shooter is adjacent to any wall/gate — shooting from the battlements). Gates (0x220506) count as walls only for side 0. Unit formula = 2 × (closeness-to-hex-centre in x [0..23] + in y [0..15] − arc height), summed over every sample point inside that hex, clamped to 100; wall values take max per hex. So "%" = how centrally the line crosses the occupied hex, reduced by lob height (boulders clear walls once height ≥ 34; 67 → 0).

**Executor (NextStrike ≈0x40EE41):** walks the block list in order, `Random(100) < rec+8` → projectile stops there: target := unit on that hex (else wasted; obstacle-object 0x220166 / wall / gate / terrain), XYZ path truncated. Independent sequential rolls ⇒ P(reach target) = Π(1 − p_i/100).

**AI TCAI.EvalPath 0x414DA8(cai, edx=&DEV, ecx=target, stack: objective, self, wallShot byte, targetY, targetX, shooterY, shooterX, ability, id) → returns loss = DEV_before − DEV_after; DEV := DEV·Π(1−p_i) + Σ P(reach i)·p_i·EvalHex(i)** — exactly the executor's model. Only ability categories 1/2/3/5/6/7/0x1B... (AbilTypes ladder @0x414DE9) qualify, else returns 0 untouched. EvalHex 0x414754: unit on hex (≠ target): value via ability VMT+0xEC(self, unit) → tcDVtoDEV 0x413664 → MultDEV 0x414418(×max HP): enemy → +, own side → − (friendly fire priced at full damage value); wallShot byte (1 only for Hurl Boulder 0x18 and id 0x2C) → walls valued +/− via WallMaxHP table 0x4675F8 for side 0/1. Terrain/obstacle blockers contribute 0 (pure loss). EvalBreath 0x415138 = EvalPath (units flag 0) + 12 BreathHN neighbour hexes.

**Ranged handler in CheckUnit (0x417420, 2026-09-15 patch hooks at 0x417451/0x417510 sit BEFORE all of this):** ladder @0x4175AD routes ids 0x16,0x19,0x2D,0x37,0x39,0x3A,0x3D,0x3E,0x78–0x7C → EvalPath(flag 0); 0x18,0x2C → EvalPath(flag 1); 0x1E,0x56–0x5A → EvalBreath; every other id reaching the handler gets NO obstacle evaluation (loss 0). Only evaluated when the target is in range NOW ([ebp-0x1C] ≤ R, R = 12/8/4 from ability VMT+0x84 == 5/4/else). Frame: [ebp-0x28] DEV0 (pre-path), [ebp-0x64] DEV after path, [ebp-0x58] loss, [ebp-0x68] terrain path self→target (index 0 = self), [ebp-0x6C] second path (best alternative spot → end).
- **(a) obstructed now (loss>0):** backwards search i = count−2…1 over the terrain path (stops dead at the first wall hex unless self has ability 0x01/0x24/0x42; candidate must be ≤ R hexes from the START hex), EvalPath from each, keep strictly-lower loss (nearest-to-target on ties). If found: path2 = path[best..], MakeTerrainPath → positional [ebp-0x54], and **[ebp-0x58] := loss_best + DEV_best = DEV0** (the better spot's own residual obstruction is thrown away — looks like a bug/sloppiness, unverified in play).
- **(b) always:** forward loop i = 1…count−2 of hexes within R of the target and reachable this turn; accept only PERFECTLY clean ones (loss == 0 AND DEV untouched from the 0x3E8 sentinel — 100 % pass, no friendly/enemy in the line); the LAST qualifying index wins (closest to target) and path[0..i−1] are deleted so the path starts there. Partially blocked spots are never traded off here.
- **Move types (phase-5 jump table @0x41A4E8, verified 2026-09-18): 0 → walk 0x41A500, 1 → touch 0x41ABD0, 2 → melee 0x41A9EA, 3 → AbRangedTC 0x41AE24 = FIRE NOW at (+0x1C,+0x1E), 4 → nothing 0x41AEF1 (temp), 5 → the SAME walk handler as 0** (type-5 extras: [unit+0x5C] clamped to the cost of reaching the spot @0x41A8AA; destination on a wall/gate hex with a 2-entry path → moves zeroed @0x41A7DE). Game rule (user, 2026-09-18): any movement, even one hex, disables ranged attacks for the rest of the turn ⇒ type 5 is "walk to a firing spot, shoot NEXT turn", never move-and-shoot. The 0x417CB1 check (VMT+0x94 == [self+0x5C]) is exactly "has not moved yet = may still fire".
- Values: in range & unmoved → type 3 @0x417D79 (shoot now) = DEV_cur·DEV_cur/|DEV_cur+[ebp-0x58]| (obstructed ≈ DEV0·(1−ℓ)²; clean = DEV0), then type 5 @0x417E62 (walk to path2[0], the less-obstructed spot found in (a)) = ([ebp-0x58]+pos)·[ebp-0x58]/|…| ≈ DEV0·1/(1+(1−ℓ)) — a positioning move valued by NEXT turn's shot, and since [ebp-0x58] = DEV0 it assumes that spot is clean even when it is only "less obstructed". Else branch @0x417E6C (out of range now, or already moved, or hero unsafe): type 5 @0x417F7E = walk to path[0] (the clean spot from (b)) valued DEV_cur+[ebp-0x58]+pos = DEV0 × VMT+0x94 pct; if (b) found nothing, path[0] is the unit's own hex → a zero-length "walk" proposal (harmless stand-still, not a wasted shot). Hero self: UnitSafe 0x4138B8 trims the path to the last safe hex (0x417B5B–0x417C5C) and an unsafe current hex suppresses shoot-now when non-heroes exist ([cai+0x30] ≠ 0).
- Alternative spots are only ever hexes ON the terrain path to the target — the AI never sidesteps to clear an obstacle.
