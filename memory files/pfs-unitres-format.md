## PFS CONTAINER (= HSS object tree, see [[raise-terrain-underground]] for the table format)
- `Unitres.pfs`: `magic 0x2144DF1C` · `01 00 00` · root property table @7. **`HEROES.PFS` has NO magic** — starts `01 00 00` + table @3.
- Property table: `[ctrl b][nd:dword if b&0x80][nb=b&0x7F × (tag:byte,off:byte)][nd × (tag:dword,off:dword)]`, offsets **relative to table end** (data base). Engine reader = `TEReadStorageStream` (EngineP.dpl); every `rw*` does `FindOffset(tag)` — **tag-indexed, not sequential** (why raw scanning failed for non-Human records).
- Root field **1 = children table** (child id → offset; children base = table end). Unitres: 187 children (sparse ids 0..292 = editor unit-resource IDs). Child record = `[classid:4][table][data]` (TUnitResource classid 0x20212).

## UNIT RECORD TAGS (from TUnitResource.ReadWrite @0x55784DE4 → obj offsets [0x29..0x2e] etc.)
- **0xA** = race ShortString **or the unit name if 0xB absent** (independents/monsters — 94 of 187!). **0xB** = name.
- **0xE–0x13** = ATK/DEF/DMG/HP/Move/RES bytes (255 = no melee). **0x14** = level. **0x1B** = gold cost (u32). **0x1A** = description `[len:u32][chars]` (no type byte). 0xC = move-type byte.
- **0x19 / 0x1E / 0x1F = base / Silver / Gold ability owners** (sub-table): inner tag **2** = count word (=registered-ability count at save time), **3** = bitfield, **bit i = has ability id i**. Leveled entries (Marksmanship I–V etc.): regex `02 00 02 0a 00 0b 01 <lvl> <id> 00` within the owner span (id must be in bitfield).
- Validated: Human Archer (2/2/1/5/26/2, cost 8, Archery/Concealment/Walking → Fearless+Marks I → Marks II+Strike), Cavalier (cost 95, leveled Charge/Parry tiers).
