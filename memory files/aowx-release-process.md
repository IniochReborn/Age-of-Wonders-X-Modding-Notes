Release flow (done for 1.37.406 on 2026-08-22):

1. User edits `X\Documentation\changelogs.txt` (release notes source; NOT shipped in the zip). The user also keeps plain-txt sources in `X\Documentation` for other manual sections and asks to mirror them in — e.g. `HTML Overview Tab, Installation.txt` and `thanks acknowledgments.txt` (mirrored 2026-08-23; Overview text lives TWICE in the manual: content JSON `{"t":"h"/"p"...}` blocks AND a plain-string search-index array — update both; the Thanks block exists once).
2. Mirror the new entry into `.AoWx Manual.html` (root, hidden dot-file, ~7MB, single giant line 188). The changelog lives in an embedded JSON array: `"changelog": [{"date", "title", "items": [...]}]`, newest first. Items: `{"t":"h","x":"<Section>"}` headers (Items/Units/Spells/Structures/Miscellaneous/Map Playlist — plain text, no icon mapping), `{"t":"p","x":"...","lvl":0-3}` bullets (lvl = txt indent depth, clamped at 3), `{"t":"gap"}` between sections. Also bump `"lastupdated": "Last updated <date>"` near the `"version"` field. File too big for Read/Edit tools — use a byte-level Python script with count==1 asserts (pattern: scratchpad update_manual_406.py; makes `.bak_406`-style backup).
3. Copy updated manual over `upload\index.html` (website copy).
4. Run `python "patch scripts\build_release_zip.py" --prev <N-1> --next <N> --apply --manual` — re-reads the previous zip's namelist from disk, refuses on missing files, reports changed entries for eyeballing (dry run without --apply). `--manual` refreshes `upload\.AoWx Manual.zip` + `upload\index.zip` (single entry index.html). `--drop "a;b;c"` (added for 406) removes retired files — 406 dropped `Age of Wonders X - Launcher.exe`, `AoWx - Scroll of Slickness.ahk`, `AoWx - Scroll of Slickness.exe`.

Re-cutting the SAME release (done for 406 on 2026-08-23 evening, savedate fix): keep --prev at N-1 (405) and --next N (406) — the script diffs against the N-1 zip's namelist, so the SAME --drop list must be repeated (406: "Age of Wonders X - Launcher.exe;AoWx - Scroll of Slickness.ahk;AoWx - Scroll of Slickness.exe"). Then rebuild installer with the same --ver. The script's default --prev is stale (403) — always pass both explicitly.
Only `py -3.12`/`python` (3.12) exists on this machine; the `py -3.10` in script docstrings fails.
Releases land in `upload\AoWx_1_37_<N>.zip`; user uploads that folder's contents.
