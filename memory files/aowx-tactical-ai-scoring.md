**Decision cycle (TCAI phase machine @0x41818C, [cai+0x1C] phase 0..5, table @0x4181DB):** phase 0 (0x4181F3) rebuilds lists — cai+8 own controlled units (non-heroes inserted at FRONT, heroes appended LAST; [cai+0x30]=non-hero count), cai+0xC allied-player units, cai+0x10 ENEMIES, cai+0x14 move list, cai+0x18 objectives; [cai+0x2C]=0. Phase 1 (0x418AE5) per own unit [cai+0x20]: offensive ability list (ids 1..0xA9, AbilTypes≠0, GetCombatInfo byte0 & 2, scan @0x418B3E) × enemies (cai+0x10) @0x418EE0, then FRIENDLY ability list (byte0 & 1, scan @0x418F3E) × own units cai+8 (incl. self, NOT allies) @0x419201. Phase 2 (0x419541) objectives. Phase 3 (0x419C27) support score → move+0x10. Phase 4 (0x419EE0) hero fallback moves, adds +0x10/4 into +0xC, selection-sorts moves by +0xC desc. Phase 5 (0x41A4AA) executes the top move; then back to phase 0. **[cai+0x2C]** = attack moves proposed this cycle (melee 0x415709, touch 0x4171CF/0x41730A, ranged 0x417CCB/0x417DF9); every target loop skips a HERO self when it is ≠0 (0x418E89/0x4191AA/0x4198CE) → heroes only get evaluated in cycles where no non-hero could attack.
