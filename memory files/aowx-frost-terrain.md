**Applied 2026-09-14 to the 410 prerelease (`patch scripts\patch_frost_terrain_v1.py`, backups `*.bak_frost` on AoWEPACK.dll, Dict\ResStr.mld, Dict\Release.mld, Release\Spells.pfs; UNTESTED in-game).** Port of BXL's `build_icestorm_lava.py` + `build_gripofwinter.py` with the user's rules.

- **Storm callbacks:** every storm overrides `ChangeStormTerrain(eax=storm, edx=field, ecx=&terrain byte)`, `ret 4`; `TIceStorm.ChangeStormTerrain 0x557CCED4`: Water→6, Ice→refresh TFrozenWaterHS (classref cell 0x55714774, countdown +0xC, owner +0xD), catch-all `mov [ecx],3; jmp 0x557CCF39` at **0x557CCEF0** (5 B). Ice Storm spell and **Altar of Ice** both create the same class (classref cell 0x557CB3DC) → one hook covers both. ⚠ **`TBlastStorm.UpdateStorm 0x557CCAC0` re-applies the callback over the whole disc at frames `[storm+0x10]` = 8/0xC/0x12/0x16 (radius 1..4)** — any non-idempotent mapping chains (BXL's lava→wasteland→snow needed a random skip gate). Our cave (0x55816000) converts lava only when `[ebx+0x10]==0x16` (last pass, ebx=storm) → all lava ends as wasteland, nothing else changes, no RNG.
- **Freeze Water:** `TFreezeWaterTE.ChangeTerrain 0x5579E884` (eax=TE, edx=field, ecx=&terrain; ebx=ecx inside): GetArmyHS gate → hook site **0x5579E89B** (`0F BE 03 66 85 C0`, resume 0x5579E8A1, epilogue 0x5579E8F7); vanilla arms 0→6, 0xA→0xD, 6/0xD→refresh marker, else nothing. Cave 0x55816040: 9→5; 1/2/4/5→3; else vanilla. `TerrainChanged 0x5579E900` mints the melt marker only for new ice → land changes permanent. Target gates `ValidTargetMapF 0x5579EBA0` / `ValidTargetSelectionMapF 0x5579EBF0` (15 B each: `movsx edi,[reg+0x14]; test; je; cmp di,0xA; jne reject`) → `EB 0D` + NOPs; **both must move together**. Terrain ids: 0 Water 1 Grass 2 Desert 3 Snow 4 Steppe 5 Wasteland 6 Ice 7 EarthWall 9 Lava A CaveWater C Dirt D CaveIce. Our dll has the pristine `mov edx,0xB` countdown at 0x5579E96A (BXL's 0x20 orphan edit is not ours). Free CODE caves: 0x55816000–0x5581605F used; **0x558160C0..0x55860000 zero** (also 0x55813955–0x55813B80, 0x558155EE–0x55815800).
- **Path of Frost (unit ability 0x6D):** `TAbstractUnit.PathOfFrostTerrainChange 0x557801E4` (eax=unit, edx=field → edi, ecx=&terrain): 0→6, 0xA→0xD, ice→refresh marker (countdown 2), then an **AoWx-added land arm at 0x55780231** (`8A 01 48 2C 02` = mov al,[ecx]; dec eax; sub al,2 → 1/2/4/5 → snow, surface only via `[edi+0x12]==0`; not vanilla — BXL's audit lists vanilla as water-only). Hooked there → cave 0x55816080: lava→wasteland (surface only), else replays dec/sub and resumes at the `jb` 0x55780236; epilogue 0x55780246. Level gating (user ruling 2026-09-14): **Ice Storm's lava branch is surface-only** (`field+0x12==0`, esi=field); **Freeze Terrain and Path of Frost cool lava on every level** (underground lava→wasteland is wanted even though the underground editor palette is water/dirt/lava/ice/earth/rock); Path of Frost's AoWx snow arm keeps its own surface gate; earth/rock (7/8) and dirt (0xC) are never converted by any of the three. The script rebuilds every file from its `.bak_frost` when present, so re-tunes re-apply cleanly.
