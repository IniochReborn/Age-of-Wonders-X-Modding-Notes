HOW THE VANILLA EFFECTS DRAW (RE)
  Air Mastery (strategic, AoWEPACK): TAirMastery.ExecuteTE starts an animation object; draw callback 0x557F050C runs
  90 ticks and EVERY tick draws N = 5 / 20 / 10 (detail setting [[0x558E945C]+0x6D] = 0 / 1 / other) sprites from the
  spell's gfx slots 0..2 = pfs 70: MAGIC.ILB 160 / 161 / 162 (Cloud01-03.BMP, 201x118, drawMode 770 blend 30;
  xs/ys -100/-53, -95/-53, -97/-56; kind 4, one frame) at x = Random(screenW) + 2d, y = Random(screenH) - d with
  d = (tick - 45) * (Random(15) + 5), slot = Random(3).  Fresh random positions every tick -> flickering clouds whose
  distribution streaks up-right across the screen over the 90 ticks.
  World Healer (327) / Overgrowth / Ice Age = the same callback drawing their own slots 0..2 (same scatter pattern).
  Winds of Fury (combat, kind 0x2F): its particles are kind-0x1F effects spawned @0x42BFE8 carrying the parent's
  [fx+0x14]/[fx+0x18] (= spell 0x7E) on a swirl path (0x402E0C).  A kind-0x1F draws slot 0 of [fx+0x18] = pfs 136
  slot 0 = PARTICLE.ILB [18,19,20,19] (19x19 blue-white glow orbs, 770/50, -9/-10), frame = frames[fx_ptr mod 3],
  through GFXE's Intensity table at L = 100 - 100*tick/pathLen (fades along its path).
  => a kind-0x1F effect with [fx+0x18] = 0x7E IS a Winds of Fury particle (identical image, blend, fade, flicker).
  Ilpack GetTotalSequenceFrames (kind 4) = frames * (f18 + 1); a kind-0x26 driver expires when that many ticks ran.
